# mech-ctrl-patent-valuation

> 机械装置 + 控制方法组合型专利 · 价值评估 Skill

## 一、功能简介

针对**同时包含「机械结构装置权利要求」与「软件/算法/流程控制方法权利要求」的组合型专利**，提供一套融合全球主流专利价值评估方法论的标准化、结构化价值评估能力。

- 区分**法律、技术、市场、方案本身、实施风险、权利要求质量**六大维度，兼容定量指标与定性研判；
- 内部拆为**七大模块**：基础元数据、法律价值、技术方案价值、市场商业价值、实施落地风险、跨专利对标、综合评分输出；
- 融合 **WIPO / IPscore / Ocean Tomo / Relecura / 国知局专利价值分析指标体系 / LRF**，并叠加机械-控制组合专利**专属修正因子**；
- 输出分项研判 + 关键风险清单 + 综合价值分级 + **多页 A4（2–3 页）图表报告**。

四个专属修正因子（Cf1–Cf4）：

| 因子 | 含义 |
| --- | --- |
| Cf1 | 控制方法侵权取证难度系数（外部可观测×1.0 / 需反向工程×0.6–0.8），乘入法律价值分 |
| Cf2 | 软硬件成熟度不一致扣分（\|机械TRL−控制TRL\|≥2 触发） |
| Cf3 | 创新贡献拆分系数（机械/控制占比），用于加权与许可-规避分析 |
| Cf4 | 权利要求装置-方法对应缺陷扣分 |

脚本 `scripts/generate_report.py`：读取评估 JSON，输出**自包含多页 A4（2–3 页）HTML 报告**（内嵌 SVG 五维雷达、贡献拆分甜甜圈、TRL 双条、价值期望对比），无第三方依赖、可离线使用。

## 二、必要说明

- **适用对象**：机械装置 + 控制方法组合型专利（智能装备、机器人、自动化产线、机电一体化等）。不适用纯机械、纯算法、外观设计专利（仅作部分参考）。
- **输入**：专利文本（权利要求书、说明书、附图）、同族/法律状态元数据，可选外部输入（TRL、目标市场规模、对比文件）。
- **调用方式**：
  ```bash
  python scripts/generate_report.py <评估结论.json> [输出.html]
  ```
- **依赖**：Python 3，仅标准库；SVG 图表内嵌，离线可用。
- **输出**：五维雷达、贡献拆分、TRL、价值期望对比、风险清单、修正因子、体系溯源；综合价值分级（高 / 中高 / 中 / 中低 / 低）及「现有估值 → 未来期望值变化」（相对量纲，**不输出绝对金额**——金额需财务参数属外部输入）。
- **核心规则文件**：
  - `references/methodology.md`：全维度检查清单、全球评估体系短板与溯源、修正因子定义。
  - `references/scoring_rubric.md`：0–5 打分刻度、综合评分公式、分级阈值、未来期望规则。

## 三、案例

**专利**：一种基于自适应控制的智能装配机械臂装置及方法（示例 CN112345678B，授权有效，中欧美三法域同族，剩余 16 年）。

1. **判定组合场景**：③ 装置 + 控制耦合，必须一起使用。
2. **五维打分（0–5）**：法律 4.0、技术 3.5、市场 4.0、权利要求质量 3.0、实施落地 3.5。
3. **专属修正因子**：
   - Cf1 = 0.8（控制逻辑运行于控制器内，需反向工程取证）；
   - Cf2 = −6（机械 TRL 7 / 控制 TRL 5，成熟度差 2 级）；
   - Cf3 机械 0.6 / 控制 0.4；
   - Cf4 = −3（方法步骤与装置构件基本对应，存在轻微缺陷）。
4. **综合评分**：加权得 72 → **中高**；未来期望 81（随量产落地与头部许可，预期上升至高）。
5. **关键风险**：高等级「控制方法侵权取证需反向工程，外部不可直接观测」；中等级「机械加工公差影响算法工况达成（实施耦合风险）」「纯控制方法易被调参/换序规避」。
6. **交付物**：多页 A4（2–3 页）图表报告（雷达 + 甜甜圈 + TRL + 价值期望 + 风险清单 + 修正因子 + 体系溯源）。

## 四、关联技能

- `mech-ctrl-patent-interpret`（组合专利标准化结构化解读）：先解读、后评估，二者互补。解读产出的 `structure` / `control_flow` 结构化数据可直接支撑本 Skill 的技术维度拆解、TRL 判定与实施耦合/规避风险研判。
