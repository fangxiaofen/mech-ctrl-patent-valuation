# 评分量表与综合分级规则

本文件定义各维度的打分刻度、权重、专属修正因子计算公式、综合价值分级，以及“现有估值 + 未来期望值变化”的输出规则。供 `scripts/generate_report.py` 与人工研判共用。

---

## 1. 维度打分刻度（0–5 分，半分制）

每个维度按以下描述锚定得分（先定性，再落到半分）：

| 维度 | 5 | 3 | 1 | 0 |
| --- | --- | --- | --- | --- |
| 法律价值 | 多法域授权、无无效/纠纷、剩余期限>10年 | 单/双法域授权、期限适中、有轻微争议 | 仅申请/实审、期限短、有驳回风险 | 已驳回/无效/权属灭失 |
| 技术价值 | 创造性高、定量效果明确、机械与控制均高TRL | 中等创新、效果定性、TRL中等 | 改进微小、效果模糊、TRL低 | 无新颖性/被现有技术覆盖 |
| 市场商业价值 | 核心专利、大市场、可拆分许可、头部愿实施 | 优选改进、中等市场、许可受限 | 周边配套、小市场 | 无商业场景 |
| 权利要求质量 | 独权完整清晰、多层从属防御、无对应缺陷 | 基本完整、少量模糊、防御一般 | 功能性限定多、存在对应缺陷 | 公开不充分/独权重大缺陷 |
| 实施落地可行性 | 供应链成熟、软硬成熟度一致、无标准壁垒 | 基本可行、有调试成本 | 耦合风险明显、易规避 | 无法产业化 |

> 技术维度内部强制拆分三块（报告与图表必现），**且每块均独立打分后再加权合成技术维度分**：
> - 【机械装置创新评价】→ 子分 `SM`（0–5）
> - 【控制方法创新评价】→ 子分 `SC`（0–5）
> - 【软硬件耦合协同创新评价】→ 子分 `SK`（0–5）
>
> **其余维度（法律 / 市场 / 权利要求质量 / 实施落地）按世界流行方法（WIPO / IPscore / Ocean Tomo / Relecura / 国知局指标体系 / LRF）直接打分，不另行加权；综合研判（composite）才是各类价值的加权打分。**

### 1.1 技术三维子分刻度（SM / SC / SK，0–5 半分制）

| 子分 | 5 | 3 | 1 |
| --- | --- | --- | --- |
| SM 机械装置创新 | 机械构型/运动副/装配原创且效果定量显著 | 中等结构改进、效果定性 | 简单替换、效果模糊 |
| SC 控制方法创新 | 控制逻辑/调度/闭环原创、可复现增益 | 中等算法改进 | 常规 PID/调参、无增益 |
| SK 软硬件耦合协同 | 机械-控制协同产生 1+1>2 的超额定量效果 | 有一定协同效果 | 仅并列、无协同增益 |

### 1.2 技术维度加权合成

`技术价值 = wm·SM + wc·SC + wk·SK`（wm+wc+wk=1，权重见 Cf3）

- 纯机械装置专利：wm=1.0，wc=wk=0 → 技术价值 = SM
- 纯控制方法专利：wc=1.0，wm=wk=0 → 技术价值 = SC
- 耦合协同专利：例 wm=0.4、wc=0.4、wk=0.2

`Technical_100 = 技术价值 / 5 × 100`（与 §2 其余维度统一到 0–100）。

## 2. 综合评分公式

### 2.1 维度归一化
`dim_100 = dim_score / 5 × 100`（各维度 0–100）。

### 2.2 取证难度修正法律分
`Legal_adj = Legal_100 × Cf1`（Cf1 ∈ [0.6, 1.0]，见 methodology §六）。

### 2.3 加权基础综合（综合研判 = 各类价值加权打分，0–100）
```
Composite =
  0.25 × Legal_adj          # 法律价值（世界流行方法打分 × Cf1）
+ 0.30 × Technical_100      # 技术价值（§1.2 三维子分加权：wm·SM+wc·SC+wk·SK）
+ 0.20 × Market_100         # 市场商业价值（世界流行方法打分）
+ 0.15 × ClaimQuality_100   # 权利要求质量（世界流行方法打分）
+ 0.10 × Feasibility_100    # 实施落地可行性（世界流行方法打分）
```
> 说明：法律/市场/权项质量/落地四个维度各自按世界流行方法（WIPO/IPscore/Ocean Tomo/Relecura/国知局/LRF）独立打 0–5；技术维度由三维子分加权得到；五维再按上式加权得到综合研判分。

### 2.4 修正项（叠加）
```
Composite_final = Composite
  + Cf2            （软硬件成熟度不一致扣分，∈ [−10, 0]）
  + Cf4            （装置-方法对应缺陷扣分，∈ [−10, 0]）
```
截断至 [0, 100]。

## 3. 综合价值分级

| 最终分 | 等级 | 含义 |
| --- | --- | --- |
| ≥ 80 | 高 | 法律稳、技术强、市场大、风险可控，高价值资产 |
| 65–79 | 中高 | 整体优良，存在局部短板（如取证难或成熟度不一致） |
| 50–64 | 中 | 有价值但多项中等，需补强权利要求或成熟度 |
| 35–49 | 中低 | 明显短板，价值依赖特定场景或补正 |
| < 35 | 低 | 法律/技术/市场任一重大缺陷，价值有限 |

## 4. “现有估值 + 未来期望值变化”输出规则

### 4.1 现状值
`Value_now = Composite_final`（0–100，相对量纲，**不输出绝对金额**——金额需财务参数属外部输入）。

### 4.2 未来期望调整（趋势修正，∈ [−15, +25]）
逐项判定并累加：
- **技术进化成熟度上升**：mechanical_TRL 或 control_TRL 正在提升 / 样机转量产 → +0~8；
- **商业资本青睐**：已有许可、转让、投资、诉讼/无效对抗活跃 → +0~8；
- **专利动态正向**：被引用增长、无无效、同族扩布局 → +0~5；
- **风险拖累**：易规避（尤其纯控制方法）、取证极难、标准壁垒高 → −0~15。

`Value_future = clamp(Value_now + 趋势修正, 0, 100)`。

### 4.3 方向判定
- Value_future − Value_now > 3 → **上升 ↑**
- 差值的绝对值 ≤ 3 → **平稳 →**
- Value_future − Value_now < −3 → **下降 ↓**

### 4.4 输出形式
以“现状值 → 未来期望值”双水平条 + 方向箭头呈现（见报告生成脚本），并附一句定性说明（如“当前中高价值，随量产落地与头部许可，预期上升至高”）。

---

## 5. 输入参数（供开发/调用）

- **必填**：专利文本（权利要求书、说明书、附图）。
- **元数据**：同族信息、法律状态、申请人、申请日、地域。
- **可选外部输入**：TRL 等级、目标应用市场信息、现有技术对比文件。
- **模式选择**：【分析评价模式】/【对标全球评估方法模式】。

## 6. 输出字段

- 各维度定性分析文本（技术部分强制拆分机械/控制/耦合三块）；
- 专属修正因子计算说明（Cf1–Cf4）；
- 关键风险清单（权利要求缺陷、取证难度、软硬件耦合、规避难度）；
- 引用的全球评估体系溯源；
- 综合价值等级（高/中高/中/中低/低）+ 定性说明；
- 现有估值 + 未来期望值变化（图表，多页 A4 2–3 页）。
